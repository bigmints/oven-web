# PicoRunner identity revision

The first thin, rounded logo was rejected. The new direction follows the
user's reference: strong typography, solid black geometry, sharp corners,
and effective monochrome reproduction. The reference was not traced.

The user selected **02 — Folded P**. This folder preserves both concepts:

1. **Forward:** an angular, forward-leaning R with heavy uppercase lettering.
2. **Folded P:** a geometric P constructed from solid planes with heavy
   mixed-case lettering. Recommended for its connection to PicoRunner and
   the reference's compact, architectural character.

`directions.svg` and `directions.png` compare primary, inverse, app-icon, and
small-size uses. Individual symbols, wordmarks, lockups, and app icons are
provided as SVG. Lettering is outlined from the locally licensed Arial Black;
the files do not embed or distribute the font software.

Run the Swift helper to regenerate outlined text, then
`node design/brand-v2/build-concepts.mjs` to rebuild the SVG concepts.
Production assets are generated by `scripts/build-brand.mjs` and `scripts/render-brand.mjs`. Folded P is applied to the website and desktop. The release candidate is rebuilt after embedded artwork changes.
