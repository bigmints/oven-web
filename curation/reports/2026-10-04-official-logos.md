# Official app logos only

The owner requires that app listings never use non-official logos. The existing renderer drew custom leaf, sunrise and chat symbols for Flourish, Rise and Youbot, and substituted a generic grid for other app names. These app identity graphics are removed from home previews, catalog cards and details pages. App names remain visible without substitute logos.

No upstream logo assets were imported or claimed as verified in this change. Future official assets require an upstream source and checked license or usage permission; invented marks, initials and generic symbols cannot stand in for project logos. This policy is recorded in the curator skill.

Layout spacing is adjusted for text-only cards. The PicoRunner brand and ordinary interface icons are unchanged. A regression check covers home, catalog and all seven details pages. Existing README excerpts, licensing and GitHub actions remain intact.

Publication uses the existing GitHub Pages workflow; the live pages are checked after deployment.
