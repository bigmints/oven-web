# Coolify candidate assessment — 2026-10-06

Scope: eight consumer apps identified from Coolify's one-click catalog. All seven passing candidates were tested on an Apple Silicon Mac with macOS 26.6.2, Docker Desktop, and a PicoRunner debug build containing the same container recipes as [PicoRunner 0.3.14](https://github.com/bigmints/oven-site/releases/tag/v0.3.14). A separate release-mode QA app with its own bundle ID installed, launched, and restarted CyberChef. No upstream repository was modified. Each automated native test used a fresh, disposable PicoRunner library and removed only its own installation.

PicoRunner's automated native checks for each passing row: source checkout, pinned image pull, Compose start, repeated local HTTP readiness, stop/start, clean container and network removal, and removal of its disposable PicoRunner installation and registry record. The separate browser action checks below establish that the launched UI was the expected app. Those browser actions used disposable containers with the same pinned images; they were not performed inside the automated PicoRunner test library.

## Release and publication

PicoRunner 0.3.14 contains these recipes. Release preflight passed with Rust tests serialized after a parallel port-readiness test proved flaky. A separate release-mode QA app installed and restarted CyberChef from its repository and opened the expected local browser UI. Apple accepted app submission `cf8e4ccb-575c-4fb6-b403-13b57f7deff1` and DMG submission `702ae77b-9abc-471c-a8a2-aa9ab622fd24`; both tickets were stapled and validated. Code signature, Gatekeeper, and DMG integrity checks passed. Public DMG and updater archive URLs returned HTTP 200 with lengths matching the packaged files. Source commit: `d232b5477ca29ee405560dea3edbc9c6942e0b2e`; its [source archive](https://github.com/bigmints/oven-site/releases/download/v0.3.14/PicoRunner_0.3.14_source.tar.gz) is attached to the release. The seven app tests were conducted against the debug build; only CyberChef received the additional release-mode GUI check.
